# Credits & Acknowledgments

Pokémon Yellow++ wouldn't have been possible without the work of the Pokémon ROM hacking community. Many features were inspired by, adapted from, or built upon publicly shared projects, code, documentation, and tutorials.

## Base Project

- [dannye/pokeyellow-gen-2-gfx](https://github.com/dannye/pokeyellow-gen-2-gfx) — the base disassembly with Generation 2 graphical enhancements.
- [pret/pokeyellow](https://github.com/pret/pokeyellow) — the underlying Pokémon Yellow disassembly and community resources.

## Yellow++ Contributions

Alongside adaptations of the work credited above, Yellow++ includes many original features and changes developed for this project. Some of these have also been shared with the community through the [pokered wiki tutorials](https://github.com/pret/pokered/wiki/Tutorials).
